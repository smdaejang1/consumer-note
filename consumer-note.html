❓ 소비자 관리 노트 작성 요령

소비자와의 소통을 계획하고 기록하며 3% 얼라인을 관리하는 도구입니다.
1️⃣ 소비자 등록 & 기본 설정
👤 소비자 등록
첫 화면 이름 입력 → [추가] 버튼
레그·구분·관계발달·3개월 목표 설정 후 저장
🤝 관계발달
개인적: 1관심 → 2친한 → 3신뢰 → 4승승
사업적: 1관심 → 2이해 → 3확신 → 4실행
📌 3개월 목표
당월·익월·익익월별로 목표 클릭 → 저장
1개 제품 / 5개 제품 / 도움받는 3% / 스스로 3% / 복제하는 3%
⭐ 목표 설정 → 3% 얼라인 현황과 연동되어 방향 제시 박스에 자동 반영!
예) 장스오 목표 설정 시 → "장스오 단계" 자동 인식 → 다음 액션 제시
2️⃣ 이번 달 만남 계획 (도전카드)
📅 날짜 추가
기본정보 하단 → 날짜 선택 → [날짜 추가] 버튼
날짜별 계획표가 자동 생성됩니다
📋 Thinking / What&Why / How
Thinking: 이 만남의 핵심 마인드셋
What&Why: 무엇을, 왜 할 것인가?
How: 어떻게 접근할 것인가?
→ 제품·사업·시스템 3개 영역을 한 표에 작성
📝 실행 기록 자동 연동 ⭐
① 계획 먼저 작성
날짜별 표에 Thinking / What&Why / How 입력 후 [💾 저장]

② 만남 당일 [📝 실행 기록] 버튼 클릭
→ 제품·사업·시스템 탭이 자동으로 열리면서
→ 계획에 작성한 내용이 파란색으로 자동 입력됩니다
→ 실제 결과(피드백)만 추가로 입력 후 저장하면 완료!

⚠️ 파란색 = 계획에서 온 내용 (수정 시 검정으로 변경)
⚠️ 검정색 = 직접 입력한 내용
💾 저장 & 완료 처리
[💾 저장]: 계획 저장 (만남 전 언제든 수정 가능)
[🔒 완료 처리]: 만남 후 계획 잠금 (수정 불가)
3️⃣ 실행 기록 입력
📦 제품 탭
제품군 클릭(11개 브랜드) → 제품명 → 니즈 → 진행 → 피드백
→ 🎯 3% 액션 선택 → 단계 선택 → 저장
⭐ 제품군 선택 시 활동 현황 카드에 브랜드별 자동 집계!
예) 뉴트리라이트 3개, 아티스트리 1개 → 활동 현황에 자동 표시
💼 사업 탭
니즈 → 진행(STP 내용) → 피드백
→ 🎯 STP 선택 → 단계(소개/이해/파트너) → 저장
🎓 시스템 탭
시스템명 입력 → 니즈 → 진행 → 피드백
예) OM세미나, FED, 월례회의, 특강
→ 🎯 3% 액션 선택 → 단계 선택 → 저장
⚠️ 3% 액션은 중복 선택 가능!
카탈로그·장스오·STP가 한 번에 이루어질 수 있습니다.
해당 액션을 모두 선택해 주세요.
4️⃣ 활동 현황 & 방향 제시
🤝 소통 기록 (자동 집계) ⭐
제품·사업·시스템 탭에 기록 입력 → 소통 기록 자동 반영
이번 달 소통 횟수 자동 카운팅 (별도 입력 불필요!)
→ 기록을 성실히 할수록 소통 횟수가 자동으로 쌓입니다
→ 모든 기록은 통계 화면에도 자동 반영됩니다
📋 활동 현황 3카드
📦 제품 결과 / 💼 사업 결과 / 🎓 시스템 결과

★ = 현재 분기, 데이터 있는 분기만 자동 표시
💡 방향 제시 박스
3% 얼라인 현황 분석 → 다음 액션 자동 제시
🌱 시작 → 📋 카탈 → 🛒 장스오 → 💼 STP → 🎉 3% 완성
5️⃣ 3% 얼라인 개념
📋 카탈로그 → 🛒 장스오 → 💼 STP → 🌱 복제
📋 카탈로그
내가 잘 활용하는 제품을 소비자에게 공유하는 나만의 카탈로그
🛒 장스오
장바구니 스마트 오더 — 정기 구매 습관화로 소비자를 완성
💼 STP
카탈로그·장스오 경험을 스토리로 만들어 파트너에게 공유
